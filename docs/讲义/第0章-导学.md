# 第 0 章 · 导学

> 对应总大纲 `docs/compose/spec/ai-embedded-teaching.md` 第 0 章。本章 1 讲。

---

## 0.1 这套课怎么学

- **时长**：15 分钟
- **画面形式**：实拍（成品演示）+ 板书/录屏（课程地图）+ 动画（三层模型）
- **本讲目标**：学员清楚这门课要学什么、不学什么、用什么学、以及怎么用 AI 辅助而不被 AI 带偏。

### 前置

无需任何前置。学员手里只需要：一台能上网的电脑、会写 C 语言（指针、结构体、位操作能看懂）。

### 知识点

**1. 这门课的定位：原理入门是主线，智能车/电赛是载体**

- 不是「智能车速成课」，也不是「电赛刷题课」。
- 主线是嵌入式入门原理：工具链、寄存器、外设、调试、工程化。
- 智能车 / 电赛的作用有三个：
  1. **动机**：让学员知道学这些原理最后能做出什么（循迹小车、电机调速、赛题作品）；
  2. **引入**：每讲用一个真实场景开头（点灯→电机使能、按键→碰撞开关、PWM→电机调速）；
  3. **收束**：第 4 章用智能车核心功能做最终项目，第 6 章讲赛题拆解方法。
- 关键话术：「车只是例子，原理才是你带得走的东西。」

**2. 课程地图（6 章 + 平台切换）**

```
第0章 导学
第1章 环境搭建 ──────── STM32 + Keil + VSCode/Copilot + 烧录/串口
第2章 从C到寄存器 ───── STM32（概念通用）
        ↓  中途切平台
第3章 用AI写代码 ────── ESP32 + VSCode + ESP-IDF + Copilot
第4章 工程框架与迭代 ── ESP32，收束智能车核心
第5章 调试实战 ──────── 双平台
第6章 电赛/智能车收束
```

- **为什么中途切平台**：STM32 资料全、寄存器手册经典，适合把「原理」讲透；ESP32 生态活跃、Copilot 对 ESP-IDF 熟悉度高、自带 WiFi/BLE，适合把「AI 协作 + 工程化」落地。
- 切换点在第 3 章开头（3.1），会专门讲「换平台不换概念」。

**3. AI 辅助学习三层模型**

| 层 | 占比 | 做什么 | 例子 |
|----|------|--------|------|
| 知道 | 30% | 用 AI 加速理解概念、查资料、看代码 | 「volatile 是干什么的？」「这个寄存器位域什么意思？」 |
| 验证 | 50% | 动手做、跑起来、观测现象 | 编译→烧录→串口看日志→改参数看变化 |
| 攻克 | 20% | 做 AI 做不到的事 | 用示波器量波形、判断时序、定位硬件故障 |

- 关键话术：「AI 帮你把『知道』的成本降下来，但『验证』这一步没人能替你。」
- 本课最大的坑：**AI 会编造寄存器地址和位定义**。第 3 章会专门教怎么防，但从今天起就要建立「AI 说的话必须对照手册验证」的本能。

**4. 硬件清单概述（展开见附录 A）**

三档预算：

| 档位 | 内容 | 用途 |
|------|------|------|
| 必备 | STM32F103C8T6 最小系统板、USB-TTL、ST-Link/DAP-Link、杜邦线、面包板 | 第 1–2 章 |
| 必备 | ESP32 开发板（DevKitC 或同类）、USB 数据线 | 第 3–6 章 |
| 必备 | 万用表 | 贯穿全程 |
| 建议 | 智能车套件（TB6612/L298N 驱动板、直流减速电机×2、灰度/红外循迹模块、超声波模块、电池盒） | 第 2.7、4.5、6 章 |
| 可选 | 逻辑分析仪（24MHz 8 通道即可）、入门示波器 | 第 5 章 |
| 可选 | OLED 屏（I2C 0.96 寸）、DHT11/BME280 温湿度 | 第 3.5 综合实战 |

### 演示步骤

1. **实拍成品演示（2 分钟）**：上电一台循迹智能车，演示循迹、避障、调速；切到开发板演示点灯、串口输出。
   - 话术：「这是这门课最后你能做出来的东西。今天先不讲它怎么跑，先讲我们怎么一步步走到这里。」
2. **屏幕录制：课程地图（3 分钟）**：打开总大纲文档，逐章划过，指出平台切换点。
3. **屏幕录制：三层模型（2 分钟）**：用一个真实例子演示——让 AI 解释 `volatile`（知道层），然后自己写个带 volatile 的代码跑一下（验证层），再用示波器看信号（攻克层）。
4. **实拍：硬件清单摊开（2 分钟）**：把清单里的东西摆桌上，逐一指认，说明哪章用到。

### 口播要点

- 开场钩子：「你 C 语言已经会了，但为什么让你点个灯、读个传感器，还是不知道从哪下手？」
- 定位澄清：「这门课不追新外设、不刷赛题，把套路讲熟。车只是例子，原理才是你带得走的东西。」
- 平台切换预告：「前两章用 STM32 把原理讲透，第三章开始换 ESP32 练真功夫——别怕，概念是通用的。」
- AI 红线：「AI 会编造寄存器地址。它写的每一行寄存器操作，你都要能对照手册指出来是哪一页。做不到，就别让它写。」
- 三层模型落地：「30% 知道、50% 验证、20% 攻克。这一课最怕的不是学不会，是以为『AI 写了』就等于『你会了』。」

### 踩坑提醒

- 学员容易一上来就问「买什么车好」「哪个开发板最强」——拉回来：先把手里的最小系统板点灯跑起来。
- 学员容易把 AI 当搜索引擎用（问一堆概念不验证）——提醒：本课每个概念都要动手跑一遍。
- 学员容易低估硬件采购周期——提醒：今天就下单第 1–2 章要用的东西（STM32 板 + 下载器 + USB-TTL）。

### 课后动作

1. 按附录 A 把「必备」件加入购物车（先不急着下单智能车套件）。
2. 装好 VSCode 与 GitHub 账号（Copilot 的开通在 1.3 讲细讲）。
3. 想一想：你身边有没有一个「想做但不知道怎么开始」的硬件小项目？写一句话。后面每章结束可以回头对照它。
